02 // Mudança de Paradigma

O que muda da geração v2.x para o Forge-SDD 3.0

ARQUITETURA ANTERIOR (v2.x) Fluxo Linear Único
TOPOLOGIA
Agente único acumulando papéis A mesma sessão que escrevia o código era responsável por revisar a própria entrega, reduzindo o rigor crítico.
EXECUÇÃO
Processamento estritamente sequencial Mesmo tarefas sem relação entre si precisavam aguardar uma única fila manual em texto.
CONTEXTO
Constituição monolítica Todas as regras do projeto eram carregadas integralmente a cada sessão, consumindo janela de contexto com instruções irrelevantes à tarefa.
APRENDIZADO
Catalogação manual de padrões Habilidades reutilizáveis dependiam de criação manual pelo desenvolvedor.
NOVA ARQUITETURA (v3.0.0-beta) Orquestração Distribuída
TOPOLOGIA
Separação estrita em 5 Estações Concepção, Planejamento, Construção e Auditoria operam com permissões isoladas sob coordenação do Líder.
EXECUÇÃO
Motor de fila com detecção de colisão O binário avalia os arquivos tocados: tarefas independentes rodam em paralelo; dependências aguardam na fila automaticamente.
CONTEXTO
Constituição por IDs + Regras sob demanda Princípios imutáveis ficam em 1 página indexada; guias operacionais detalhados são carregados somente quando a tarefa exige.
APRENDIZADO
Motor de Auto-Skills (Regra de Três) Procedimentos repetidos 3 vezes são convertidos e sincronizados automaticamente como Skills reutilizáveis.
03 // Governança em 3 Camadas

Visibilidade executiva sem ruído operacional.

Nenhuma entrega chega à sua tela sem antes atravessar duas barreiras técnicas independentes. Você recebe apenas o diagnóstico consolidado para decidir:

CAMADA A // PORTÃO DETERMINÍSTICO CLI GO NATIVO

Validação instantânea de testes automatizados, ausência de credenciais expostas, limites de arquivo e vínculo com a especificação.

CAMADA B // AUDITORIA SEMÂNTICA READ-ONLY AGENTE INDEPENDENTE

Cruza o código entregue contra os IDs da Constituição e emite veredito fundamentado em evidências (conforme, ressalvas ou bloqueado).

CAMADA C // PAINEL EXECUTIVO DO LÍDER DECISÃO HUMANA

Apresenta o que já foi concluído, o estado de cada estação, eventuais habilidades aprendidas e o que resta no backlog.
