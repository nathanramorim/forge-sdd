Começando com o Forge-SDD

O Forge-SDD é um orquestrador de desenvolvimento que conecta você e sua IA num fluxo de trabalho claro: você decide, a IA implementa, você aprova.

Instalação

Instale o CLI globalmente com npm:

npm i -g @nathanramorim/forge-sdd

Inicialize no seu projeto

Dentro do seu repositório, rode:

forge init

Isso cria a estrutura sdd/ com tudo que a IA precisa para trabalhar.

Prompt para IA 
Instale o forge-sdd neste projeto:
npm i -g @nathanramorim/forge-sdd
forge init
Me diga quando estiver pronto e mostre o que foi criado.

Primeira feature

Com o forge-sdd instalado, você pode pedir à sua IA para criar a primeira feature:

Prompt para IA 
Vamos criar nossa primeira feature com o forge-sdd.
Execute: /discovery adicionar comando forge greet que imprime "Olá, mundo!"
Aguarde minha aprovação antes de implementar.

Jornada ideal

O Forge-SDD organiza o trabalho em três papéis simples. Você não precisa saber programar — só precisa tomar decisões.

1

Discovery

Você descreve o que quer. A IA analisa o projeto, levanta riscos e monta um plano detalhado. Você lê e decide se faz sentido.

2

Builder implementa

Depois da sua aprovação, a IA segue exatamente o plano: escreve o código, cria os testes e abre um PR pronto para revisar.

3

Você aprova

O PR chega sem surpresas. Você revisa o diff, aprova e faz o merge. Se não estiver bom, a IA corrige até ficar.

Exemplos práticos

Veja como adicionar uma feature real do início ao fim.

Adicionar comando forge greet

Neste exemplo, vamos adicionar um comando que imprime "Olá, mundo!" no terminal.

  1. Inicie o discovery.

    Mande o prompt abaixo para sua IA:

    Prompt para IA 
    Inicie o discovery para: adicionar comando forge greet
Execute /discovery e me mostre o plano antes de implementar.
  2. Aprove o plano.

    A IA vai mostrar o que pretende criar. Se estiver certo, diga "aprovado" ou "pode implementar".

  3. Revise o PR no GitHub.

    Quando a IA terminar, ela abre um PR com o código. Você revisa o diff e faz o merge.

Hub mode — um forge para vários repos

Em vez de rodar forge init em cada repo separado, você elege um repo como hub e os outros como satélites. O hub rastreia o status de todos os projetos do time em um único lugar.

Passo a passo

  1. Inicialize o repo hub.

    No repositório que será o hub central, rode:

    forge init
  2. Vincule os repos satélites.

    Para cada repo do time que você quer rastrear:

    forge init --link ../outro-repo
  3. Veja o status de todos.

    No repo hub, rode forge pipeline para ver o estado de cada repo vinculado:

    forge pipeline
Prompt para IA 
Configure o forge-sdd como hub neste workspace.
O repo atual é o hub. Para cada repo satélite, rode:

Prompt para IA
