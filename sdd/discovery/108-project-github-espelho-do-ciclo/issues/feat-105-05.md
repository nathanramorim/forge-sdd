## Problema que resolve
O painel de situação mostra trabalhos já terminados misturados com os que estão em andamento.

## Como resolve
Esconde o que está concluído e oferece uma opção para mostrar tudo.

## Valor para quem usa
Quem olha o painel vê só o que precisa de atenção.

## Em que ponto está
Há código num PR em rascunho, com as verificações informadas pelo construtor no próprio PR; falta a conferência do revisor e a decisão do dono. Ainda não foi mesclado.
