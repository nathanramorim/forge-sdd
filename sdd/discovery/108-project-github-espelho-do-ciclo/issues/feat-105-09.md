## Problema que resolve
As especificações são técnicas demais para quem acompanha o projeto sem programar, e as notas de versão saem sem um texto simples para aproveitar.

## Como resolve
Exige em toda especificação nova uma seção curta e honesta, em linguagem comum, dizendo o que a entrega muda.

## Valor para quem usa
Quem decide e quem acompanha entende cada entrega sem ler detalhes técnicos.

## Em que ponto está
A especificação foi aprovada junto com a iniciativa. Ainda não foi construído.
