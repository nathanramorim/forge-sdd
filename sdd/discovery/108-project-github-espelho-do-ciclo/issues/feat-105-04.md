## Problema que resolve
O verificador de saúde do projeto não avisa quando a versão do projeto ficou para trás e despeja uma lista longa que esconde o que importa.

## Como resolve
Compara a versão do projeto com a do programa e só mostra a lista completa quando a pessoa pede.

## Valor para quem usa
Problemas de versão aparecem na hora e a tela fica curta.

## Em que ponto está
Há código num PR em rascunho, com as verificações informadas pelo construtor no próprio PR; falta a conferência do revisor e a decisão do dono. Ainda não foi mesclado.
