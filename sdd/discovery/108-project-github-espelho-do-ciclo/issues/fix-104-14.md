## Problema que resolve
O guia inicial explica o mesmo fluxo de trabalho duas vezes, em versões diferentes, e confunde quem chega.

## Como resolve
Mantém uma única explicação, atualizada.

## Valor para quem usa
Quem lê o guia entende o fluxo de primeira.

## Em que ponto está
Há código num PR em rascunho, com as verificações informadas pelo construtor no próprio PR; falta a conferência do revisor e a decisão do dono. Ainda não foi mesclado.
