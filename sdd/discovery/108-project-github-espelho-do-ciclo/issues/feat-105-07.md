## Problema que resolve
Não há registro de quais comandos antigos ainda estão sendo usados, então não dá para decidir quando removê-los com segurança.

## Como resolve
Cada vez que um comando antigo é usado, anota uma linha numa planilha do próprio projeto.

## Valor para quem usa
A remoção futura é decidida com dados, não por palpite.

## Em que ponto está
Há código num PR em rascunho, com as verificações informadas pelo construtor no próprio PR; falta a conferência do revisor e a decisão do dono. Ainda não foi mesclado.
