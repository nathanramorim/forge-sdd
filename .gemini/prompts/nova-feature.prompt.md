# Prompt: nova-feature

**Uso:** Peça "/nova-feature <descrição>"

**Ação:**
1. Acione a lógica de **Specifier**.
2. Crie a branch da feature localmente (`git checkout -b feat/<nome>`) **antes** de criar os arquivos.
3. Crie o arquivo `sdd/features/feat-XX-<nome>.md` com base na descrição.
4. Defina um critério de conclusão executável.
5. Atualize `sdd/features/index.md` e `sdd/memory/progress.md`.
